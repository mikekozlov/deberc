# Дебертц — счётчик очков

Самодостаточное PWA для подсчёта очков в дебертце (пары 2×2, игра до 1010 по умолчанию): раунды с байтом/терцами/беллой/капотом, история партий, статистика игроков и пар, экспорт/импорт JSON.

Стек: один `index.html` (vanilla HTML/CSS/JS), service worker, manifest. Без фреймворков и сборки.

## Правила подсчёта

- Сырые точки, сумма раздачи без комбинаций = 162 (последняя взятка +10 включена)
- Терц = 20, полтинник = 50, белла = 20
- Байт: заказавшая пара набрала меньше — все её очки (включая комбинации) уходят соперникам; ничья — каждый пишет своё
- Конец игры: после раздачи ≥ цели; обе перешли — у кого больше; равенство — ещё раздача

## Использование на iPad

Открыть страницу в Safari → Поделиться → «На экран "Домой"». Данные хранятся в localStorage установленного приложения — вносить результаты после установки. Регулярно делать «Экспорт данных» в Настройках (удаление иконки удаляет данные).

## Синхронизация между устройствами

Общие данные лежат в скрытом GitHub Gist (id зашит в `SYNC` в `index.html`). Чтение — у всех автоматически: при запуске и возврате в приложение подтягивается облачная копия, если она новее локальной (сравнение по `updatedAt`, последняя запись побеждает). Запись — только с устройств, где в Настройки → Синхронизация вставлен GitHub-токен (fine-grained PAT с единственным правом «Gists: Read and write»); каждая правка данных отправляется в gist с задержкой 4 секунды, перед отправкой облако проверяется на более свежую версию. Токен хранится в отдельном ключе localStorage и не попадает ни в экспорт, ни в gist. Одновременная запись с двух устройств не поддерживается (перезапишет последняя).

## Деплой

GitHub Pages из ветки `main`. При любом изменении файлов поднять версию в двух местах: `CACHE` в `sw.js` и `APP_VERSION` в `index.html` — иначе установленные приложения не получат обновление.

## Самотест движка

В консоли браузера: `runSelfTest()` — 12 кейсов подсчёта (обычная раздача, байт, комбинации, капот, ничья, финиш).
