# Дебертц — счётчик очков

Самодостаточное PWA для подсчёта очков в дебертце (пары 2×2, игра до 1010 по умолчанию): раунды с байтом/лижей/батоном/комбинациями, подсказка раздающего, история партий, статистика игроков и пар, экспорт/импорт JSON.

Стек: один `index.html` (vanilla HTML/CSS/JS), service worker, manifest. Без фреймворков и сборки.

## Правила подсчёта

- Сырые точки, сумма раздачи без комбинаций = 162 (последняя взятка +10 включена)
- Терц = 20, полтинник = 50, деберц (6+ подряд) = 100, белла = 20
- Байт: заказавшая пара набрала (взятки + комбинации) меньше соперников — все её очки уходят соперникам
- Лыжа: пара набрала (взятки + комбинации) 12 или меньше — пишет −100, соперники пишут свои взятки и свои комбинации. Лыжа перекрывает байт
- Батон: одна пара взяла все взятки (162). Победители пишут 162 + свои комбинации; проигравшие 0, но их 3-й и последующие батоны за игру — по −100. Этот штраф — не лыжа: в таблице он помечен отдельным бейджем «×3»
- Ничья в раздаче — каждый пишет своё
- Раздающий: первый выбирается при создании игры, дальше по кругу (игрок пары 1 → игрок пары 2 → второй пары 1 → второй пары 2); приложение показывает, кто раздаёт
- Конец игры: после раздачи ≥ цели; обе перешли — у кого больше; равенство — ещё раздача

## Синхронизация

Данные лежат на домашнем ПК: `ts-serve/data/deberc-journal.json`, эндпоинт `GET/PUT /api/journal/deberc` в `ts-serve/serve.py`. Аутентификации нет — доступ ограничен тайнетом, все устройства читают и пишут автоматически. Чтение при запуске, возврате в приложение и фоновым тиком каждые 25 c (throttle 20 c), запись с debounce 4 c. Последняя запись побеждает по `updatedAt`; на устаревший PUT сервер отвечает 409 с актуальной копией, и устройство обновляется вместо перезаписи. Одновременный ввод с двух устройств не поддерживается.

## Деплой

Изменения: поднять версию в двух местах (`CACHE` в `sw.js` и `APP_VERSION` в `index.html`), запушить в `main`, затем на ПК выполнить `powershell -File C:\Users\mykha\ts-serve\sync_pages.ps1` — библиотека тайнета обновится из GitHub.

## Самотест движка

В консоли браузера: `runSelfTest()` — кейсы подсчёта: байт, лыжа, батон (включая 3-й со штрафом), деберц, ничья, ротация раздающего, финиш.
